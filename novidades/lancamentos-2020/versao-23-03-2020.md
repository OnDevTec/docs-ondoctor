<ReleaseEntry type="novidade" title="Emissão de alertas gerais e de retorno">


Foi criado o recurso para que você possa emitir um alerta para qualquer usuário do sistema, existem duas formas de emitir um alerta: Após finalizar um atendimento aparecerá uma opção para emitir um alerta para agendamento de retorno, ou indo em 'Configurações > Política de Mensagens > Alertas'.

</ReleaseEntry>


<ReleaseEntry type="novidade" title="Anexo de arquivos do cliente">


Foi adicionado o recurso para anexar imagens e documentos de cada cliente, como exames, radiografias, entre outros. Para anexar um arquivo, basta acessar o cadastro do cliente desejado e ir na aba 'Anexos'.

</ReleaseEntry>


<ReleaseEntry type="novidade" title="Financeiro do sistema">


Foi adicionado o módulo financeiro do sistema, para que você possa gerenciar todos os seus pagamentos e custos referentes ao sistema em uma única dashboard. Para acessar o financeiro do sistema basta clicar no ícone do carrinho no menu principal.

</ReleaseEntry>


<ReleaseEntry type="novidade" title="Botão para acesso a agenda">


Foi adicionado um botão para acessar a agenda na dashboard principal.

</ReleaseEntry>

### Janela Modal

Foi feita uma correção para ao abrir uma janela modal, não interagir com os outros componentes de fora.

### Relatório Modal

 Foi feito uma alteração para que os relatórios ocupem a tela inteira.


<ReleaseEntry type="novidade" title="Medicamento">


Adicionada a opção de adicionar um novo medicamento ao fazer a prescrição do cliente.

</ReleaseEntry>
