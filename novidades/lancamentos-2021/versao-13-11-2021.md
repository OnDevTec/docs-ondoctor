# Versão - (13/11/2021)

### Guia da Solicitação de Exame

Agora no sistema foi adicionado na solicitação de exame a opção para gerar a guia quando o paciente possui convênio.

![](/assets/guia-da-solicitacao-de-exame.png)

### Estatísticas De SMS

Agora no sistema foi criado um modulo de estatística que mostra as médias dos gastos de SMS(Crédto de Mensagens) do sistema podendo filtrar por perído, e sua média.

![](/assets/estatisticas-de-sms.png)

### Sala De Espera

Foi criado no sistema um modulo de sala de espera na qual é listando todos os agendamentos do dia que estão com o status "Chegou".

![](/assets/sala-de-espera.png)

### Protocolo - Solicitação De Exame

Foi adicionado no sistema a opção para ser criado um protocolo a partir de uma solicitação de exame.

![](/assets/protocolo-solicitacao-de-exame.png)

### Protocolo - Prescrição De Receituário

Foi adicionado no sistema a opção para ser criado um protocolo a partir de uma de medicamento.

![](/assets/protocolo-prescricao-de-receituario.png)

### Visualizar Agendamento em Lista

Agora no sistema você pode visualizar a agenda de forma detalhada em lista.

![](/assets/visualizar-agendamento-em-lista.png)

### Prontuário Inicio Pelo Assistente

Agora no sistema um profissional pode permitir que outro usuário possa m iniciar o prontuário e emitir exame ou receituário, no entanto, somente o profissional poderá finalizar ou emitir.

![](/assets/prontuario-inicio-pelo-assistente.png)
