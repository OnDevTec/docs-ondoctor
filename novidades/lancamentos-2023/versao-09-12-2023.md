# Versão - (09/12/2023)

## PAINEL DE ATENDIMENTO

Nesta atualização foi adicionado o recurso **Painel de atendimento.** O objetivo desta opção é possibilitar ao Atendente ou Profissional, através da sala de recepção e/ou atendimento, chame o próximo paciente a ser atendido.

Para ativar o recurso: `Configurações>dados da equipe>Grupos, aba "Atendimento"` 

<figure><img src="/assets/painel-de-atendimento.png" alt=""><figcaption></figcaption></figure>

Para configurar o recurso: `Configurações>Dados da empresa>Parâmetros>Atendimento`

<figure><img src="/assets/painel-de-atendimento-2.png" alt=""><figcaption></figcaption></figure>

Primeiramente é necessário gerar o link do painel usando a opção "Gerar link". Após o link ser gerado, você pode atualizar o link com essa mesma opção. Esse link você vai utilizar para acessar a pagina do painel no navegador.

<figure><img src="/assets/painel-de-atendimento-3.png" alt=""><figcaption></figcaption></figure>

É necessário definir um código de acesso para entrar no painel quando acessar o link gerado anteriormente. _Obs: mínimo 4 caracteres, por padrão o OnDoctor insere o código **1234**._

<figure><img src="/assets/painel-de-atendimento-4.png" alt=""><figcaption></figcaption></figure>

Em vídeo, você pode inserir o link do vídeo que irá ser exibido no painel de atendimento para os pacientes que estão aguardando serem atendidos assistam. 

<figure><img src="/assets/painel-de-atendimento-5.png" alt=""><figcaption></figcaption></figure>

Feed RSS é um tipo de link que os sites de noticias geralmente possuem para exibir informações. Você pode inserir  esse link e o OnDoctor começará a exibir as informações na tela do painel de atendimento para os pacientes. Exemplos de Feed RSS: [https://rss.uol.com.br/](https://rss.uol.com.br/)

<figure><img src="/assets/painel-de-atendimento-6.png" alt=""><figcaption></figcaption></figure>

Após configurado, basta salvar.

## DOWNLOAD DE ARQUIVO

Agora é possível baixar o PDF de Atestados/Docs, Prescrições e Exames através do link de autenticação que é gerado dentro destes arquivos na parte inferior da página.

Sendo necessário apenas ler o Qr-Code ou acessar através do link que é disponibilizado. Com isso será redirecionado para a pagina de autenticação do arquivo e nela terá a opção "Baixar Arquivo". 

Ao clicar nesta opção para baixar será necessário inserir um código. Este código é disponibilizado dentro do documento na parte de **"Código de Desbloqueio"**.

## SIGILO

Agora é possível definir nas permissões dos grupos se o usuário que pertence aquele grupo vai poder visualizar os lançamentos que estão com sigilo. Esta opção é recomendada para Administradores, responsáveis técnico e etc.

Quando marcada a opção ![](/assets/sigilo-2.png) o grupo poderá **visualizar** os lançamentos que estão com a opção ![](/assets/sigilo-4.png) ativa.

Quando marcada a opção ![](/assets/sigilo-3.png) o grupo poderá **alterar o status** de sigilo dos lançamentos, ativar ou desativar o sigilo no registro.

_Obs: Essa opção serve para os lançamentos de TODOS os usuários._

<figure><img src="/assets/sigilo.png" alt=""><figcaption><p>Configurações>dados da equipe>grupos</p></figcaption></figure>

## ANEXO DE PASTAS E ARQUIVOS

Agora é possível fazer o upload de pastas com arquivos diretamente para o OnDoctor. Para isso é necessário apenas arrastar a pasta para dentro do sistema. Semelhante a demonstração abaixo.

Outra melhoria nas pastas foi a visibilidade. Agora é possível definir se uma pasta vai ser exclusiva do paciente ou poderá ser usada no cadastro de todos os pacientes.

<figure><img src="/assets/anexo-de-pastas-e-arquivos.png" alt=""><figcaption><p>Paciente>Anexos</p></figcaption></figure>

<figure><img src="/assets/anexo-de-pastas-e-arquivos-2.png" alt=""><figcaption><p>Pasta</p></figcaption></figure>

_Obs: O sistema não irá permitir que esta opção seja desmarcada caso a pasta contenha arquivos._
