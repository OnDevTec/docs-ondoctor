## AGENDA RECORRENTE

Foi adicionado no OnDoctor a possibilidade de criar agendamentos recorrentes a partir de um agendamento modelo. Para usar a opção, basta ir até o agendamento que será recorrente e usar a opção ![](/assets/agenda-recorrente-3.png).

Após marcar a opção o sistema vai pedir para que realize a configuração de sua recorrência.

<figure><img src="/assets/agenda-recorrente-4.png" alt=""><figcaption></figcaption></figure>

Primeiramente você pode selecionar os dias que o agendamento vai ser realizado.

![](/assets/agenda-recorrente-5.png)

E após isso, selecionar o período em que deseja que o sistema gere os agendamentos, o término da recorrência.

<figure><img src="/assets/agenda-recorrente-2.png" alt=""><figcaption></figcaption></figure>

Tendo como opções: 

* Nunca: O sistema nunca vai parar de gerar os agendamentos, entretanto, você precisa informar um valor em _"gerar os próximos X dia(s)"_ para o sistema gerar esses agendamentos até o número de dias informado. Tendo como limite gerar até os próximos 365 dias;
* Em: Informar a data na qual você quer que o sistema termine de gerar os agendamentos(Limite de 1 ano);
* Após: Nesta opção, você pode informar quantas ocorrências(Quantos agendamentos) você quer que o sistema gere(Limite 50).

Após configurar basta usar a opção "gerar" e imediatamente o sistema vai começar a gerar os agendamentos tendo como modelo o agendamento utilizado e a configuração de recorrência feita. 

<figure><img src="/assets/agenda-recorrente.mp4" alt=""><figcaption></figcaption></figure>

## CUSTO PRODUTO X PROCEDIMENTO

Agora o OnDoctor calcula automaticamente o valor de custo de um procedimento que tenha produtos vinculado, com base no valor de compra do produto vinculado a ele.\
\
Conforme for vinculando produtos ao procedimento, o valor no campo ![](/assets/custo-produto-x-procedimento.png) vai sendo lançado e atualizado.

Tendo como base o valor de compra que está no cadastro daquele produto, multiplicado pela quantidade de produto informada e vinculada ao procedimento. 

**Assim como nas imagens abaixo!** 

<figure><img src="/assets/custo-produto-x-procedimento-2.png" alt=""><figcaption><p>Produto>Valor compra</p></figcaption></figure>

<figure><img src="/assets/custo-produto-x-procedimento-3.png" alt=""><figcaption><p>Procedimento</p></figcaption></figure>

_Obs: O sistema permite apagar ou alterar o valor de custo para R$0,00 ou para o valor de sua preferência._
