## CONFIGURAÇÃO DE ACESSO

Agora é possível gerenciar os acessos ao OnDoctor, para que os usuários não façam uso da ferramenta fora do ambiente da clinica.

Para isso basta realizar a configuração acessando _Configurações>Dados da empresa>Parâmetros>Segurança._

A configuração de permissão de acessos consiste em criar uma lista de IPs que quando usados tenham permissão de entrar no OnDoctor, caso o IP usado pelo usuário não esteja na lista de IPs permitidos não será possível logar na ferramenta.

Para adicionar o código do IP basta usar a opção "Adicionar meu IP", desta forma o sistema irá inserir o IP que está sendo usado naquele momento na rede de internet da clinica, e todos os usuários que estiverem conectados a internet da clinica conseguirão acessar o sistema.

<figure><img src="/assets/configuracao-de-acesso.png" alt=""><figcaption><p><em>Configurações>Dados da empresa>Parâmetros>Segurança.</em></p></figcaption></figure>

Caso exista um grupo de usuários que não tenham necessidade de fazer parte dessa configuração de bloqueio de acesso, basta marcar a opção "IP liberado" nas permissões do grupo. Com isso, mesmo que haja configuração de bloqueio nos acessos, os usuários deste grupo conseguirão acessar o sistema normalmente.

<figure><img src="/assets/configuracao-de-acesso-2.png" alt=""><figcaption><p>Configurações>dados da equipe>grupos</p></figcaption></figure>

_obs:_ 

* _IPs são informações que mudam constantemente, caso o IP mude os usuários não conseguirão mais acessar, sendo necessário alterar o código nas configurações para o novo código de IP;_
* _É ideal sempre ter um grupo com a opção "IP liberado", geralmente o grupo de Administradores._
