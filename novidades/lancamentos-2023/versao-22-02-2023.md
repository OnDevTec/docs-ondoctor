# Versão - (22/02/2023)

## GERAÇÃO DE ORÇAMENTOS

Foi adicionado uma opção "Orçamento" no prontuário para gerar solicitações de orçamentos durante o atendimento. 

Quando a opção é usada, o sistema vai gerar um orçamento com o status "Aguardando" com os procedimentos que foram selecionados. Caso sejam lançados procedimentos de convênios diferentes, o sistema irá gerar um orçamento pra cada convênio utilizado com seus respectivos procedimentos.

## NOTA FISCAL DE SERVIÇO

Na parte fiscal dentro do cadastro de procedimento foi adicionado o campo de "Descrição para Nota". Para casos onde o procedimento precisa ser exibido com outra descrição na NFS.

Também é possível a utilização de TAGS para melhor personalização. Basta clicar com o botão direito no campo de descrição para nota, que opções de TAGS serão disponibilizadas.

## CUSTO DO PROCEDIMENTO

Adicionado no cadastro do procedimento um campo para inserir o custo que aquele procedimento em especifico possui. _Obs: O custo é abatido no valor para pagamento de comissões._

##  ![](/assets/image-271.png)ANTECIPAÇÃO DE CARTÕES

Agora é possível criar títulos de cartão que funcionam com a dinâmica de antecipação. Dentro do cadastro do titulo, ao selecionar os tipos "Crédito/Débito" o sistema disponibiliza uma opção de "antecipação automática".

Marcando a opção, caso o título em questão seja usado para receber um documento de forma parcelada, ao invés do sistema gerar a mesma quantidade de parcelas para conciliação, ele irá gerar apenas 1(Uma) parcela para ser conciliada.

_obs: as taxas de cartões podem ser configuradas normalmente._

## ADIÇÃO DE ITENS NO ORÇAMENTO

Agora é possível adicionar vários itens simultaneamente no orçamento. Basta ir buscando os procedimentos e ir inserindo pelo botão ![](/assets/adicao-de-itens-no-orcamento.png). Após adicionar todos os procedimentos que deseja basta _**salvar**_, com isso os procedimentos serão adicionados dentro do orçamento.
