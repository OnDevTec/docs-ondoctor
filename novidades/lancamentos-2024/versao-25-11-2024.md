## PRONTUÁRIO

### Acompanhamento

Como melhoria agora é possível fazer o **acompanhamento** pediátrico não só em gráficos de tabela gerados pelo OnDoctor, mas também em gráficos de imagens. Para ativar esta modalidade de uso acesse _**Configurações>Dados da Empresa>Parâmetros>Outros.**_

<figure><img src="/assets/cats-32.jpg" alt=""><figcaption><p><em><strong>Configurações>Dados da Empresa>Parâmetros>Outros</strong></em></p></figcaption></figure>

_Obs: Não é possível usar ambas as modalidades ao mesmo tempo, deverá ser usado o gráfico por tabela gerado pelo sistema ou via imagem._ 

Para uso basta acessar o módulo **Acompanhamento** no prontuário e usar a opção **Registrar**. Com isso, o sistema irá habilitar a edição de imagem para que seja realizada as indicações no gráfico usando o editor. 

<figure><img src="/assets/acompanhamento.png" alt=""><figcaption><p>Simulação de Acompanhamento</p></figcaption></figure>

Após indicar os pontos de evolução do paciente basta usar a opção ![](/assets/acompanhamento-2.png) para salvar e o sistema irá gerar a nova imagem do gráfico com as indicações de evolução realizadas. 

Para desfazer uma evolução, use a opção ![](/assets/acompanhamento-3.png). O sistema sempre irá remover a ultima indicação/evolução feita. Conforme for excluindo o sistema irá retrocedendo a cada registro que foi realizado em ordem de salvamento, até chegar na imagem original do gráfico, neste caso, na imagem vazia sem indicações. 

##  LME

Como melhoria, agora é possível emitir o LME de forma avulsa não sendo necessário faze-lo a partir de uma prescrição com medicamentos de alto custo inseridos. Para isto basta incluir uma prescrição e usar a opção _**Prescrição LME**_.

<figure><img src="/assets/lme.png" alt=""><figcaption><p>Cadastro do Paciente>Prescrições</p></figcaption></figure>

Ao usar esta opção o sistema irá gerar o formulário de **LME** para preenchimento, com isso, o profissional ja pode preencher as informações e inserir os medicamentos na área de **justificativa**. 

<figure><img src="/assets/cats-31.jpg" alt=""><figcaption><p>Cadastro do Paciente>Prescrições>Prescrição LME</p></figcaption></figure>

Após preencher os dados e informações do paciente e inserir as medicações, basta gerar o LME usando a opção ![](/assets/lme-2.png).

#### Veja mais sobre o [_**LME(Laudo de Solicitação, Avaliação e Autorização de medicamentos)**_](https://docs.ondoctor.app/novidades/lancamentos-2024/versao-11-11-2024#lme).

### Regra de exceção do Sigilo

Agora é possível definir uma regra de usuários que entrarão como exceções para o sigilo dos registros de prontuário eletrônico. A opção fica localizada dentro do cadastro do profissional. 

Com esta regra os registros de prontuário ja entrarão como sigilosos mas deixando como exceção os usuários vinculados na regra configurada.
