# Versão - (02/07/2022)

### ACESSO RÁPIDO ORÇAMENTO

Adicionado botão de ORÇAMENTO no menu superior do sistema, possibilitando o acesso rápido aos orçamentos do sistema por ele.

![](/assets/menu-superior.png)

### CLIENTES ESTRANGEIROS

Agora é possível cadastrar pacientes/clientes que sejam estrangeiros, necessitando somente de marcar a opção "estrangeiro" no cadastro.

![](/assets/capturar-4.png)

### EVOLUÇÃO DE TRATAMENTO COM ESTOQUE

Agora para evoluir os tratamentos e sessões nos quais possuem produtos vinculados, é necessário primeiramente processar a movimentação de estoque que é gerada a partir do agendamento. Caso a movimentação de estoque não seja processada, o sistema não permite alterar a situação do agendamento para "ATENDIDO", finalizar o atendimento pelo prontuário ou evoluir o tratamento para "CONCLUÍDO" pelo controle de tratamentos no cadastro do paciente. 

![](/assets/capturar-6.png)

### VISALIZAÇÃO CADASTRO COMPLETO ORÇAMENTO

Assim como no agendamento, agora é possível visualizar o cadastro completo do paciente pela opção de visualização diretamente pelo orçamento.
