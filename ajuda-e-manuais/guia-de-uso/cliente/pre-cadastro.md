
# Pré-Cadastro

O recurso de pré-cadastro trás uma dinâmica mais eficiência na hora de cadastrar seus clientes. Na ação de cadastrar um paciente é possível enviar o link de pré-cadastro para o mesmo. 

Com este link o próprio cliente poderá concluir o preenchimento da ficha cadastral com suas informações.

Para uso deste recurso basta incluir um cliente, preencher com o nome, celular e/ou e-mail, após isso, usar a opção _Enviar pré-cadastro._
